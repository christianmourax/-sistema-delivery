# Sistema de Delivery

Projeto acadêmico que simula o início do desenvolvimento de um sistema para gerenciamento de pedidos e entregas de alimentos.

O sistema foi planejado para conectar clientes, restaurantes e entregadores em uma única plataforma, permitindo consultar cardápios, realizar pedidos e acompanhar o andamento das entregas.

## Sobre o projeto

Este projeto foi criado como atividade prática da disciplina de Gerência da Configuração de Software (GCS). O objetivo é aplicar conceitos essenciais de controle de versão e colaboração, entre eles:

- criação e registro de alterações com commits;
- organização do trabalho em branches;
- integração e resolução de mudanças;
- identificação de versões por meio de tags;
- documentação clara do objetivo e da evolução do projeto.

## Funcionalidades previstas

- Cadastro de clientes
- Cadastro de restaurantes
- Consulta de cardápios
- Realização de pedidos
- Acompanhamento das entregas
